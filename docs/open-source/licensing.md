# 许可与商业授权

LinkTerm 采用 AGPL 公共版本与付费商业许可证的双许可模式。本文同时说明贡献者许可协议，用于维持项目未来继续双许可发布的能力。

## 公共许可证

项目自有代码按 [GNU AGPL v3 或更高版本](../../LICENSE) 发布。你可以免费使用、研究、修改、部署、分发，也可以商业使用；但必须遵守 AGPL，包括向获得软件或通过网络使用修改版服务的用户提供完整对应源码。

AGPL 本身允许商业活动。付费授权购买的是一套不同于 AGPL 的专有许可条件，而不是对所有商业使用额外收费。

## 商业许可证

商业许可证适用于希望闭源分发、私有化交付、嵌入专有产品，或不希望承担 AGPL 源码公开义务的组织和个人。商业许可证需要付费并另行签署书面协议。

| 使用方式 | 可选授权 |
| --- | --- |
| 学习、研究、个人使用 | AGPL-3.0-or-later |
| 修改后公开源码并按 AGPL 分发 | AGPL-3.0-or-later |
| 基于修改版提供网络服务，并向服务用户提供对应源码 | AGPL-3.0-or-later |
| 闭源桌面软件、专有设备或私有化产品中集成 | 商业许可证 |
| 不公开修改源码或不提供完整对应源码 | 商业许可证 |

请在项目的 [Gitee Issues](https://gitee.com/wake_micro/link-mcp/issues) 创建标题以 `[Commercial License]` 开头的工单，简述公司/个人名称、使用场景、交付方式和预计用户或设备规模。不要在公开工单中提交密钥、合同、客户数据或其他机密信息；维护者会提供后续的非公开沟通方式。

商业报价、支持范围、更新期限、责任限制和其他条件以双方最终签署的协议为准。本文件只是授权路径说明，不构成报价、商业许可证或法律承诺。

商业许可证只能覆盖项目维护者有权授权的 LinkTerm 代码。第三方依赖、商标、硬件厂商 SDK、驱动和其他独立作品仍受各自条款约束，详见 [NOTICE](../../NOTICE)、[third-party-manifest.json](../../third-party-manifest.json) 与 [licenses/](../../licenses/)。

## 贡献者许可协议（CLA）

本协议用于确保 LinkTerm 可以继续同时提供 AGPL 公共版本与付费商业许可证。它不是版权转让：贡献者仍拥有其贡献的版权。

提交 Pull Request、合并请求或补丁，并在提交模板中确认本协议，即表示你同意以下条款。

### 1. 定义

“贡献”指你有意提交给 LinkTerm 项目的任何原创代码、文档、测试、设计或其他可受版权保护的材料；纯粹讨论、问题报告和明确标注为“Not a Contribution”的内容除外。

### 2. 版权许可

你授予 LinkTerm 项目维护者一项永久的、全球性的、非独占的、免许可费的、不可撤销的版权许可，允许其复制、修改、创建衍生作品、公开展示、公开执行、分发和再许可你的贡献，包括：

- 按 AGPL-3.0-or-later 或项目未来采用的兼容开源条款发布；
- 将贡献纳入 LinkTerm 的付费专有或商业许可证；
- 为维护、发行、托管、支持和推广项目而使用贡献。

### 3. 专利许可

对于你能够许可、且因单独使用你的贡献或将其与 LinkTerm 组合而必然被实施的专利权利要求，你授予项目维护者和 LinkTerm 接收者一项永久的、全球性的、非独占的、免许可费的专利许可，用于制造、使用、许诺销售、销售、进口和以其他方式转让该贡献。

### 4. 陈述

你声明：

- 你有权提交贡献并授予上述许可；
- 如果贡献属于雇主或其他组织，你已取得必要授权；
- 你会明确标注并说明贡献中包含的第三方材料及其许可证；
- 据你所知，贡献不故意包含他人的机密信息、凭据或未授权材料。

### 5. 无保证

除适用法律另有要求外，贡献按“原样”提供，不附带任何明示或默示保证。项目没有义务接受、使用或继续维护任何贡献。

### 6. 接受记录

贡献者应勾选 Pull Request 模板中的 CLA 确认项。维护者可以在合并前要求单独签署协议或补充身份/授权证明。若你不同意本协议，请不要提交代码补丁；你仍可提交问题报告和功能建议。

本协议是项目治理模板，不替代针对特定司法辖区的法律意见。项目所有者在接受大规模或企业贡献前应安排法律审阅。

如需根据你的具体场景判断义务，请咨询你自己的法律顾问。
