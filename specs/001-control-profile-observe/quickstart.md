# Quickstart: Control Profile Observation Auto-Open

1. Start LinkTerm.
2. Open **Control Profile**.
3. Open a saved control profile record.
4. Confirm the main screen shows the current control profile details.
5. For a serial profile, confirm a serial tab opens with the configured port, baud rate, and mode.
6. For an RTT profile, confirm an RTT log tab opens using the profile workspace root.
7. Change or close the associated session and confirm the detail region reflects the current state.
